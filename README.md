# 新三国语音插件 (xinsanguo_voice)

🎭 一个 AstrBot 插件，用于识别群聊中的新三国经典台词关键词，自动发送对应的语音片段。

## 功能特点

- 🎯 **关键词匹配**：自动识别群聊消息中的新三国经典台词关键词
- 🔊 **语音回复**：匹配成功后自动发送对应的语音片段
- 🎲 **随机选择**：当一条消息匹配多个关键词时，随机选择一个发送，避免刷屏
- 🧠 **智能判断**：自动识别消息是否需要 LLM 回复，纯玩梗只发语音，有问题则语音+回复
- 👥 **仅群聊**：玩梗功能只在群聊中触发，私聊不会触发（可配置）
- ⚙️ **可视化配置**：支持在 WebUI 中配置 LLM 唤醒词、阈值等参数
- 📋 **管理指令**：提供查看关键词列表、统计信息、重载配置等管理功能

## 安装方法

1. 将整个 `astrbot_plugin_xinsanguo_voice` 文件夹复制到 AstrBot 的 `data/plugins/` 目录下
2. 重启 AstrBot 或在 WebUI 中重载插件
3. 插件会自动加载并开始工作

## 配置说明

### 可视化配置（WebUI）

在 AstrBot WebUI 的插件管理中，可以配置以下参数：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| LLM 唤醒词列表 | 当消息包含这些词时，会触发 LLM 回复（正则表达式格式） | 见下方列表 |
| 关键词占比阈值 | 当关键词占消息长度的比例小于此值时，认为有实际内容需要 LLM 回复 | 0.5 (50%) |
| 唤醒词前缀 | 以此字符开头的消息只触发玩梗，不触发 LLM | `/` |
| 仅群聊触发 | 是否只在群聊中触发玩梗功能 | 是 |
| 随机选择语音 | 当一条消息匹配多个关键词时，是否随机选择一个发送 | 是 |

### 语音触发词配置（rules.json）

编辑 `rules.json` 文件来管理语音触发词：

```json
[
    {
        "keyword": "不可能",
        "audio": "不可能，绝对不可能.mp3"
    },
    {
        "keyword": "愤怒",
        "audio": "不要愤怒，愤怒会降低你的智慧.mp3"
    }
]
```

修改后使用 `/sanguo reload` 命令重新加载。

## 使用方法

### 自动触发
在**群聊**中发送包含关键词的消息，机器人会自动回复对应的语音。

**示例：**
- 发送 "这不可能！" → 机器人回复 "不可能，绝对不可能" 语音
- 发送 "别生气了" → 机器人回复 "不要愤怒，愤怒会降低你的智慧" 语音
- 发送 "恭喜恭喜" → 机器人回复 "恭喜爹可以称帝了" 语音

### 管理指令

| 指令 | 说明 |
|------|------|
| `/sanguo` | 显示帮助信息和当前配置 |
| `/sanguo list` | 查看所有关键词列表 |
| `/sanguo stats` | 查看触发统计信息 |
| `/sanguo reload` | 重新加载规则配置和插件配置 |

## 智能回复功能

插件会智能判断消息是否需要 LLM（大语言模型）回复：

### 触发条件

| 场景 | 行为 |
|------|------|
| 私聊消息 | ❌ 不触发玩梗（可配置） |
| 群聊普通消息 | ✅ 只发语音，不触发 LLM |
| 群聊唤醒词前缀消息 | ✅ 只发语音，不触发 LLM |
| 群聊 @机器人 + 纯玩梗 | ✅ 只发语音，不触发 LLM |
| 群聊 @机器人 + 有问题 | ✅ 发语音 + LLM 回复 |

### 默认 LLM 唤醒词列表

以下词语会触发 LLM 回复（可在 WebUI 中修改）：

- 问号：`?` `？`
- 疑问词：怎么、如何、为什么、什么是、是什么、怎样、哪个、哪些、多少、几个
- 请求词：帮我、请问、告诉我、解释、说说、介绍、推荐、建议、分析、总结、翻译、写一、帮忙、教我
- 疑问句式：能不能、可不可以、有没有、是否、能否、可以吗、行吗、好吗、对吗、以"吗"结尾

### 示例

```
# 私聊 - 不触发玩梗（默认配置）
用户(私聊): 不可能
机器人: (无反应)

# 群聊普通消息 - 只发语音
用户(群聊): 不可能
机器人: [语音] 不可能，绝对不可能

# 群聊唤醒词前缀 - 只发语音
用户(群聊): /不可能
机器人: [语音] 不可能，绝对不可能

# 群聊@机器人 + 纯玩梗 - 只发语音
用户(群聊): @机器人 不可能
机器人: [语音] 不可能，绝对不可能

# 群聊@机器人 + 有问题 - 语音 + LLM 回复
用户(群聊): @机器人 这不可能吧，你能帮我解释一下吗？
机器人: [语音] 不可能，绝对不可能
机器人: [文字] 好的，让我来帮你解释一下...（LLM 回复）
```

## 添加新语音

1. 将 MP3 格式的语音文件放入 `data/sound/` 目录
2. 在 `rules.json` 中添加对应的关键词规则：
   ```json
   {
       "keyword": "新关键词",
       "audio": "新语音文件.mp3"
   }
   ```
3. 使用 `/sanguo reload` 重新加载

## 注意事项

1. 语音文件格式建议使用 MP3
2. 关键词匹配是包含匹配，即消息中包含关键词即可触发
3. 玩梗功能默认只在群聊中触发，可在 WebUI 中修改
4. 唤醒词前缀消息只触发玩梗，不触发 LLM 回复
5. 插件自己的指令（`/sanguo`）不会触发玩梗
6. 配置修改后需要使用 `/sanguo reload` 或重载插件生效
